# Quick Start Guide

## Running the Application

1. **Navigate to the project**:
   ```bash
   cd digital-menu-generator
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```

3. **Open your browser** to `http://localhost:3000`

## Creating Your First Menu

### Step 1: Create a New Menu
- Click the "Create New Menu" button on the homepage
- You'll be taken to the menu builder

### Step 2: Add Restaurant Information
- Enter your restaurant name
- Add a description (optional)
- Upload a logo (optional)

### Step 3: Customize Colors
- Choose your primary color (main brand color)
- Choose your secondary color (accent color)
- Toggle visibility options for prices, descriptions, and images

### Step 4: Add Menu Sections
- Click "Add Section" to create a new section (e.g., "Appetizers", "Main Course")
- Enter the section name and description
- Add items to each section

### Step 5: Add Menu Items
- Click "Add Item" within a section
- Fill in:
  - Item name
  - Price and currency
  - Description (optional)
  - Upload an image (optional)
- Toggle "Available" to show/hide items

### Step 6: Choose a Template
- Click the "Choose Template" tab
- Preview and select from:
  - **Classic**: Traditional elegant design
  - **Modern**: Dark, contemporary style
  - **Minimal**: Clean and simple

### Step 7: Preview Your Menu
- Click the "Preview" tab to see how your menu looks
- Switch between templates to compare designs

### Step 8: Generate QR Code
- Click the "QR Code" tab
- Your QR code will be automatically generated
- Download the QR code image
- Copy the shareable link

### Step 9: Save Your Menu
- Click "Save Menu" in the build tab
- Your menu is saved locally in your browser

## Sharing Your Menu

### Option 1: QR Code
1. Download the QR code from the QR Code tab
2. Print it on table tents, menus, or posters
3. Customers scan to view your menu

### Option 2: Direct Link
1. Copy the menu URL from the QR Code tab
2. Share it via social media, email, or website
3. Customers click to view your menu

## Tips

- **Images**: Keep images under 2MB for best performance
- **Descriptions**: Short, appetizing descriptions work best
- **Sections**: Organize items logically (Starters, Mains, Desserts, Drinks)
- **Colors**: Choose colors that match your brand
- **Updates**: You can edit your menu anytime - the QR code and link stay the same!

## Troubleshooting

**Images not uploading?**
- Make sure images are under 2MB
- Use JPG, PNG, or WebP format

**Menu not saving?**
- Check browser console for errors
- Make sure localStorage is enabled
- Try clearing browser cache

**QR code not working?**
- Make sure you saved the menu first
- Test the link in an incognito window
- Check that the menu ID is correct
